# BookTracker  
Book and reading tracker PWA.  
"Install" it on your device. It's available completely offline after opening it once. All data is locally stored.  

## Installation  
On iOS: open the [web app](https://schiavoanto.github.io/BookTracker) on Safari, tap the share button, tap "Add to Home Screen", tap Add.  
On Android: search up "Install PWA on [browser]" where [browser] is the browser you use.
